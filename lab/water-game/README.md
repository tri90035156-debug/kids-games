# 小水滴變變變

給 6 歲小朋友的互動遊戲，十關認識水的三種樣子：冰、水、水蒸氣，以及融化、凝固、蒸發、凝結。每關一種不同的手部動作，相鄰兩關不重複；字母鍵畫在物件上，不配音。

| 關 | 主題 | 玩法 |
|---|---|---|
| 1 | 冰塊變成水（融化） | **按住** `H` 或太陽按鈕加熱，冰塊慢慢化成一灘水，放大鏡裡的小點點從排整齊變成滑來滑去 |
| 2 | 三種樣子 | **點選** `A` `B` `C`：三個放大鏡，哪個是冰、水、水蒸氣（真的水蒸氣看不見，小點點只是畫給你看） |
| 3 | 水變成冰（凝固） | **按住** `C` 或雪花按鈕冷卻，瓶裡的水結冰、冒出瓶口一點點；再按 `F`（或拖）把冰放進水裡，冰浮起來 |
| 4 | 硬硬的、會流動的 | **拖放分類**：物件 `A`～`F` 拖進 `J` 硬硬的（固體）或 `L` 會流動（液體）盆子；不放白煙 |
| 5 | 水滾了 | **繞圈**轉爐子旋鈕（或每按一次 `K` 轉一格），火變大、水冒大泡泡、上面出現白白的煙（小水珠） |
| 6 | 冷一點，熱一點 | **左右拖**溫度條（或 `A` `D`），看小點點跟著變；停在「剛好結冰」0 度與「剛好會滾」100 度 |
| 7 | 杯子出汗了（凝結） | **畫線**擦霧霧的冰飲料杯（或 `A` `S` `D` `F` 各擦一條），擦過的地方水珠流下來 |
| 8 | 冰棒慢慢變軟 | **排順序**：依序點 `A`～`D` 的冰棒圖，自動放進下一格 |
| 9 | 生活裡的變身 | **連線**：五個生活情境（`A`～`E`）連到蒸發、凝結、結冰（`J` `K` `L`）；鍵盤先按左邊字母再按右邊字母 |
| 10 | 水轉一圈（水循環） | **節奏敲**：亮光依序在太陽 `S`、水蒸氣 `U`、雲 `R` 上，跟著敲三圈 |

答錯只會彈回、輕搖、一聲低木魚；錯兩次出現光暈提示，錯三次小手示範。5 秒沒動作光暈變亮，15 秒出現手勢示範。每關結尾有印章、和弦，和一張「給家長」小卡。

## 開始玩、測試

雙擊 `index.html`（只有字型要網路）。測試用網址：`index.html?ch=3` 直接到第 3 關；加 `&fast=1` 文字不等待閱讀時間（只給測試用）。

## 給家長：事實與來源

1. 在一大氣壓（平地）下，冰在 0°C 融化。（Engineering ToolBox）
2. 水蒸氣是看不見的氣體；遊戲用小點點畫出來，只是讓孩子「看見」它在散開。（USGS Water Science School）
3. 水結冰後體積大約多 9%，所以比水輕、會浮起來，冰塊大約 1/10 露出水面；冬天水管凍裂也是這個原因。放大鏡裡冰的小點點排得比水「鬆」。（USGS Water Science School）
4. 國小三年級自然課會學「固體、液體、氣體」；第 4 關先分前兩種，因為氣體的水看不見。（國小三下自然「水的三態」單元）
5. 水滾時的大泡泡，裡面裝的是水蒸氣。熱湯上白白的「煙」其實是很小的水珠，是水蒸氣一離開鍋子遇冷就變回來的；真的水蒸氣看不見。熱水和爐火請大人在旁邊。（USGS Water Science School）
6. 100°C 是平地的沸點；越高的地方氣壓越低，水不到 100°C 就會滾，玉山頂（3,952 公尺）大約 87°C 就滾了，所以山上煮東西反而比較慢。（Engineering ToolBox 沸點海拔表）
7. 冷飲杯外的水珠來自空氣中的水蒸氣，碰到冰冷的杯子就凝結成水；台灣潮濕的季節，水珠特別多。（howtosmile 科學教育資源）
8. 冰棒除了水，還有糖。可以拿冰塊和冰棒一起放，看誰先軟。
9. 曬衣服是「蒸發」，不需要 100°C，常溫下水就會慢慢變成水蒸氣；有太陽、有風，乾得更快。（國小三下自然「水的三態」單元）
10. 太陽讓海和地面的水蒸發，水蒸氣升到高空變冷，凝結成雲裡的小水滴，再下成雨，這叫水循環。（USGS 水循環）

用詞照國小教案：融化、凝固、蒸發、凝結；氣體一律寫「水蒸氣」。遊戲裡不寫「水要 100 度才會變水蒸氣」。

## 改文字

改 `tools/content.py` → `python3 tools/build.py`（需 `pip install pypinyin`）。所有句子都在 `UI`（只顯示、不配音）；破音字用 `字[注音]` 手動指定。

## 檔案

| 檔案 | 用途 |
|---|---|
| `app.js` | 十關的流程與互動、提示光暈、印章、給家長小卡 |
| `game.css` | 這個遊戲的樣式（`wg-` 開頭）與水藍主題色 |
| `art.js` | 手繪 SVG（小水滴、冰塊、瓶子、鍋子、旋鈕、冰飲料杯、水循環…） |
| `particles.js` | 放大鏡裡的水分子小點點（canvas，每個最多 40 顆，同畫面合計不超過 60） |
| `sound.js` | 柔和音效（木琴、木魚、水滴、和弦；覆寫共用引擎的 `G.sfx`，加上 `G.note`） |
| `engine.js` `style.css` | 共用引擎與樣式（engine 小改：英文與數字連在一起不斷行） |
| `content.js` | 由 `build.py` 產生，不要手改 |
