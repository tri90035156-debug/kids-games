玩偶怎麼來？

給家長

這個遊戲講一隻絨毛玩偶（小熊）的旅行，十關、三站：原料哪裡來、工廠怎麼組裝、貿易怎麼到孩子手上。玩法只有四種：連連看（點左再點右，或按 A～E 與 1～5）、排順序（照順序點卡片，或按 1～6）、選一個（A B C）、按住塞棉花（按住畫面或空白鍵）。猜錯不罰，再試就好；每句旁白都有注音字幕，點字幕可以重聽。

內容依據：一般絨毛玩偶的絨布（plush）與填充棉（polyester fiberfill，市面常稱 PP 棉）多為聚酯纖維，原料來自石油煉製的對苯二甲酸與乙二醇聚合、熔融紡絲；安全眼（safety eyes）為塑膠眼珠加後扣墊圈，塞棉前裝上；工廠流程為裁布（刀模）→ 裝眼 → 反面縫合 → 翻面 → 填充 → 手縫封口 → 整毛 → 金屬探測（找斷針）與拉力測試 → 包裝。出口流程為裝箱 → 裝櫃 → 拖車至港口 → 貨櫃船 → 進口港海關查驗 → 倉庫 → 零售。棉花、羊毛兩種天然材料在第 1 關一起介紹，讓孩子知道材料也可以從田裡與動物身上來。
