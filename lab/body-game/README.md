# 我的身體裡面（lab/body-game）

2026-11-08 家長選定的新遊戲（規劃第七節 ②），設計書在 `設計.md`。給 6 歲小朋友的 3D 黏土遊戲：一個大頭小人身上十扇小門，每一關打開一扇，器官從門後面浮到前面放大，用手幫它動一次；每關一句結論＋「給家長」小卡（正確說法與來源），十關後總結三句。

| 關 | 門 | 3D 動作 | 鍵盤 |
|---|---|---|---|
| 1 | 嘴巴，咬一咬 | 一直點牙齒，上下牙咬合，飯糰變小、碎粒變多 | 空白鍵 |
| 2 | 食道，往下擠 | 手指沿食道往下拖，擠到哪一圈、哪一圈就縮緊 | ↓ |
| 3 | 胃，攪一攪 | 按住，胃一縮一放，飯菜攪成糊糊的 | 按住空白鍵 |
| 4 | 小腸，吸收好東西 | 3D 連連看：飯和麵／蛋和肉／青菜 → 有力氣／長肌肉長高／肚子順暢；連好後金色小點點從小腸跑出去 | A B C 再按 J K L |
| 5 | 一口飯的旅行 | 照順序點五站（嘴巴、食道、胃、小腸、大腸），飯糰一站一站跳；大腸把水吸回去 | 1～5 |
| 6 | 心臟，像幫浦 | 跟著木魚的咚咚聲壓心臟，紅色小點點沿血管跑；「去跑步了」要壓快一點 | 空白鍵 |
| 7 | 肺，像氣球 | 按住吸氣（兩個肺鼓起來、空氣點點跑進去），放開吐氣，三次 | 按住空白鍵 |
| 8 | 骨頭，撐住身體 | 3D 連連看：頭骨／肋骨／腿骨 → 保護頭腦／保護心和肺／撐住身體 | A B C 再按 J K L |
| 9 | 肌肉，拉骨頭 | 往上拉手臂：前面的肌肉縮短鼓起來；放開，手拉直 | 按住 W |
| 10 | 皮膚和睡覺 | 點掉跳過來的細菌（皮膚擋住）；點月亮讓小人睡覺，天色變暗、膝蓋的小傷口慢慢長好 | 空白鍵、M |

- 全程配音（VoAI 雅琪／聊天／0.9）：76 句、1091 點（2026-11-08 錄好）。字幕＝共用引擎的泡泡（注音、保留標點、點了重聽）。
- 可愛不噁心：器官是圓圓的黏土、顏色柔和，沒有血、沒有寫實解剖；大腸只說「變成便便」。
- 同一畫面物件最多 55 個（細菌的小刺用 InstancedMesh）。WebGL 開不了顯示一句話＋回首頁。
- 內容依據見 `設計.md` 第 6 節與 `tools/content.py` 的 `p1`～`p10`（NIDDK、KidsHealth、美國睡眠醫學會）。

改文字：`tools/content.py` → `python3 tools/build.py` → `KIDS_KEYS_FILE=seed-game/.env python3 -I pipeline/record_voice.py --games lab/body-game --max-voai 點數`。
測試：`?ch=N&fast=1`、`?fin=1`；`node pipeline/play3d.mjs --game lab/body-game --hook __bd --mode kb|ptr`；console `__bd.win()`、`__bd.aid()`。
