# 做一台機器人

給 6 歲小朋友的 3D 黏土玩具：把五個零件一個一個裝到機器人身上，r-o-b-o-t 五個字母就是五個步驟，也是機器人在歷史上一步一步被人做出來的順序。
這一題是家長在試的**新風格樣板**：主畫面零中文、一個場景、說明全部交給配音。

## 五步

| 字母 | 零件（架子上的樣子） | 裝上去會發生什麼 | 歷史對應（只在「給家長」） |
|---|---|---|---|
| r | 一捲設計圖（紙捲＋珊瑚紅綁帶） | 先落在空的轉台上，再跳上畫架攤開（紙上是機器人的線稿）；轉台上浮出半透明的機器人輪廓，後面四個零件的落點都在輪廓上發光 | 很早以前人就想要會自己動的幫手（古希臘神話的塔洛斯） |
| o | 一顆珊瑚紅齒輪 | 卡進胸口的圓窗，轉三圈；身體、圓頭、腳從輪廓變成實體；背後的發條鑰匙跟著轉（要轉過去才看得到） | 1768～1774 年的寫字人偶（發條、齒輪、凸輪） |
| b | 一對手臂，肩膀是天藍色小馬達 | 一塊方塊掉到轉台上，機器人彎腰用兩隻夾子把它舉起來、再放下 | 1961 年 Unimate 在工廠搬燙的金屬件 |
| o | 兩顆圓鏡頭眼睛 | 眼睛亮起來、眨一下；之後一直跟著手指／滑鼠看 | 1966～1972 年 Shakey 用攝影機看路 |
| t | 一片小電腦（兩個燈） | 插進頭頂的插槽；燈亮、齒輪轉、揮手、眨眼＝「接上電，動起來了」 | 1971 年有了微處理器，電腦小到能裝進機器人 |

## 每個零件的小挑戰（11/1 家長試玩後加：「玩法太單一，3 分鐘玩完」）

每裝好一個零件（r 之後），就用那個零件的本事玩三小關，一關比一關難；四種手勢都不同。失敗不出紅叉、不扣分，只講怎麼改、走回起點再試。整份玩下來約 10 分鐘。
零件的字母底下有三個小點＝三小關（黑點＝過了、紅圈＝現在這一關）。

| 零件 | 手勢 | 三小關 | 讓孩子懂的事 |
|---|---|---|---|
| o 齒輪 | 在畫面上**轉圈圈**上發條（哪裡畫都可以，一整圈＝轉一圈；鍵盤按 O 一下一圈，停 1.4 秒或 Enter 就走）。放手就走 | 旗子在 2 → 3 → 5 步；前兩關每轉一圈地上就亮一格，第三關不亮要自己數。轉太少停在半路、太多撞到軟牆，都走回起點 | 發條轉幾圈，它就走幾步 |
| b 手臂 | **點方塊**（鍵盤 ← → 選、B 搬） | 搬 1 塊 → 一大一小疊起來 → 三塊疊成塔；大的疊在小的上面會晃一晃倒下來，方塊跳回原位 | 機器人手臂搬東西、排整齊；大的放下面才穩 |
| o 眼睛 | 燈關掉 → **揮揮手**叫醒眼睛 → 手指（滑鼠、方向鍵）移到哪，眼睛的光就照到哪 | 找出藏起來的方塊 1 → 2 → 3 塊（越後面藏越遠：轉台邊、畫架旁、架子旁） | 攝影機眼睛讓機器人看到東西在哪（Shakey 用攝影機找箱子、推箱子） |
| t 電腦 | 先**按住**頭上的小電腦開機（鍵盤按住 T）；再點箭頭排程式、按播放（鍵盤 → 走、↑ 跳、Backspace 拿掉、Enter 播放） | 走 3 步 → 跳過一根木樁 → 跳過兩根木樁（6 格）。撞到木樁或牆、還沒走到，都走回起點，程式留著可以改 | 機器人照程式一步一步做；寫程式的人是你 |

- 方塊都是同一種暖橘（和裝手臂那一步搬的「燙金屬」同一種），木樁、牆、旗子、走道是木頭和紙，不多加顏色；地上「會走到哪」的圈是珊瑚紅。
- 16 秒沒動作，就再講一次這一關怎麼玩。叫醒眼睛 22 秒、按住開機 30 秒都沒動，會自己接下去（不會卡住）。
- 重開頁面：最後裝上的零件，挑戰還沒過，就從那個挑戰的第一關接著玩（存在 `robot-v1` 的 `cl`）。
- 測試網址 `?play=N&lv=L&fast=1`：直接玩第 N 個挑戰（1 齒輪、2 手臂、3 眼睛、4 電腦）的第 L 關（0～2）。console 打 `__robot.state()` 看現在在哪一關。

架子正面那條四線格就是進度：零件被拿走，那一格就自己一筆一筆寫出字母（英文母語聲音唸字母）；五個都裝好，架子上就是 `robot`。

五個都裝好以後是**結尾重播**（約一分鐘）：機器人輕輕散開、零件彈回架子、字母變淡；再照五步一個一個飛回去，配音把整個故事講一遍，最後揮手、唸「Robot.」、五個字母一起亮一下。
之後是**自由玩**：點任何一個零件（或按 R、O、B、T），重唸那個字母＋那一步的句子，並做那一步的動作；右下角 ⟲ 拆掉重做、ⓘ 給家長。

## 操作

- 桌機：按那一步的字母鍵 **R O B O T**（O 一律給下一個還沒裝的 o），零件會畫一道弧線掉進去。Cmd／Ctrl 組合鍵不算。
- 手機／平板：用手指把發光的零件拖到機器人身上發光的地方，靠近就吸進去；放在別處會滑一下再彈回架子（不算錯）。也可以直接點發光的零件。
- 碰還沒輪到的零件、按錯鍵：那個零件原地晃一下＋一聲低木魚，就這樣。
- 在空白處（或機器人身上）左右拖＝轉動轉台看各面，放手會滑一下；桌機 ← → 鍵也能轉。拿零件時機器人會自己轉回正面。
- 5 秒沒動作，光圈變亮；15 秒沒動作，現在這個零件自己往機器人跳一下（示範）。
- 進度存在 localStorage（`robot-v1`）：重開頁面接著做；做完回來就是自由玩。

## 測試網址

- `index.html?fast=1`：起點（旁白不等、不載音檔）
- `?step=N&fast=1`（N＝1～5）：已經裝好 N 個零件的樣子（挑戰都算過了），不重播動畫、不唸；`step=5` 直接是自由玩
- `?play=N&lv=L&fast=1`：直接玩第 N 個零件的小挑戰第 L 關
- `?end=1&fast=1`：直接看結尾重播
- 量測：在 console 打 `__robot.partPx()` 會回傳架子上五個零件在螢幕上的寬度（px）。375×812 手機上量到 58、62、67、62、72（每格 68px）；1280×800 桌機約 96～147。

## 配音

`tools/content.py` 的 `SAY` → `python3 tools/build.py` → `content.js` 與 `tools/narration.json`。錄音由外面的腳本自動做（`pipeline/record_voice.py`：中文 VoAI 雅琪、`en.` 開頭的用 ElevenLabs 英文母語聲音），這個資料夾裡沒有任何金鑰。
沒有音檔時，每句等「字數 × 220ms、至少 1.2 秒」再往下，畫面不會卡住。

- 中文 43 句、共 929 字（開場 2、五步 5、小挑戰 28、結尾 8）
- 英文 5 句、共 14 字元（`R.` `O.` `B.` `T.` `Robot.`，兩個 o 共用一檔）
- 依 verifier 查核改過的句子：`step.b`（Unimate 是液壓手臂、搬的是燙的金屬）、`step.t`（電腦變得好小）、`end.7`（兩百多年）。`end.8` 維持家長原稿。
- 錄好要聽的地方：「齒輪轉一轉」的「轉」要唸 ㄓㄨㄢˋ；「腦袋」「力氣」「本事」要輕聲。

## 畫風與聲音

- 米白底、霧面黏土、暖光軟影；三種顏色各有意思：機器人身體＝淡奶油、你裝上去的零件＝珊瑚紅 `#F05A3C`、馬達和燈＝天藍。架子是木頭。
- 每個零件都有果凍回彈（被碰、落地、卡進去都壓扁再彈回）；飛行是有重力的弧線；拖曳跟手略慢、朝移動方向傾斜。
- 聲音全部 WebAudio 合成：喀＝木琴短音＋低音；字母每一筆＝往上的木琴（五聲音階）；裝好一個＝上行三音；完成＝和弦；錯＝低木魚。齒輪轉動沒有聲音。
- 原創：眼睛是嵌在圓頭裡的兩顆圓鏡頭；字母筆順是自己畫的 SVG path；沒有外部圖、音檔、字型動畫。

## 給家長

robot 的五個字母，對到機器人一步一步被做出來的順序。年份是方便記的近似值。

- **r 設計圖**：很早以前人就想要會自己動的幫手，像古希臘神話裡會動的青銅巨人塔洛斯。〔[Wikipedia: Talos](https://en.wikipedia.org/wiki/Talos)〕
- **o 齒輪身體**：1768～1774 年，瑞士鐘錶匠 Pierre Jaquet-Droz 父子和 Jean-Frédéric Leschot 做出「寫字人偶」，靠發條、齒輪和凸輪，用鵝毛筆寫出最多 40 個字母。它今天還在瑞士納沙泰爾的博物館裡，而且還會動。〔[Wikipedia](https://en.wikipedia.org/wiki/Jaquet-Droz_automata)、[Linda Hall Library](https://www.lindahall.org/about/news/scientist-of-the-day/pierre-jaquet-droz/)〕
- **b 有力氣的手臂**：1961 年，Unimate 在美國紐澤西的通用汽車工廠上工，把剛壓鑄好的燙金屬件搬下來，一般公認是第一台工業機器人。（它的手臂其實是液壓推動的；今天的工廠手臂多半在關節裡裝電動馬達。）〔[The Henry Ford](https://www.thehenryford.org/collections-and-research/digital-collections/artifact/183434)、[Wikipedia](https://en.wikipedia.org/wiki/Unimate)〕
- **o 攝影機眼睛**：1966～1972 年，美國史丹佛研究院（SRI）的 Shakey 用電視攝影機和測距儀看路，是第一台會自己想步驟、再自己移動的機器人。它的「腦」是一台用無線電連線的大電腦。〔[SRI](https://www.sri.com/story/75-years-of-innovation-shakey-the-robot/)、[Wikipedia](https://en.wikipedia.org/wiki/Shakey_the_robot)〕
- **t 小電腦腦袋**：1971 年有了微處理器，電腦小到可以裝進機器人身體裡。今天的機器人靠程式知道要做什麼。〔[Wikipedia: Intel 4004](https://en.wikipedia.org/wiki/Intel_4004)〕
- **robot 這個字**：出自捷克作家 Karel Čapek 1920 年的劇本《R.U.R.》，是哥哥 Josef 建議的，來自捷克語 robota（苦工、勞役）。劇裡的 robot 是人造的人，不是金屬做的。〔[Britannica](https://www.britannica.com/print/article/512953)、[Linda Hall Library](https://www.lindahall.org/about/news/scientist-of-the-day/karel-capek-2/)〕

（b 那一行的標題是「有力氣的手臂」，故意不寫「馬達手臂」，免得跟括號裡的液壓說明打架。遊戲裡的零件照樣做成馬達。）
