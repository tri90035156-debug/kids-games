## 十關

| 關 | 標題 | 手勢 |
|---|---|---|
| 1 | 嗨！這是颱風 | 點颱風三下叫醒它（空白鍵） |
| 2 | 颱風怎麼生出來？ | 點太陽，海水變熱、水蒸氣往上飄、雲長成颱風 |
| 3 | 颱風為什麼會轉圈圈？ | 按「讓地球轉起來」看風往右彎；再用手指逆時針畫圈（← →） |
| 4 | 颱風長什麼樣子？ | 點颱風眼、眼牆、雨帶；可以放一個臺灣比大小 |
| 5 | 颱風為什麼會走路？ | 改變水流（方向鍵／點圖），樹葉碰三顆星星 |
| 6 | 颱風通常怎麼走？ | 高氣壓變大、不大不小、變小（1 2 3），再看常走的路 |
| 7 | 颱風來了，怎麼辦？ | 防颱小任務六張卡：好（A）／不好（B） |
| 8 | 經過臺灣以後，颱風去哪裡？ | 按「繼續走」三次：沖繩、東海、日本 |
| 9 | 颱風怎麼會消失？ | 拖颱風去冷海、陸地，力氣變成零（方向鍵） |
| 10 | 你是颱風小博士！ | 四題 A／B 問答 |

每關：故事一句一句唸 → 要做的事 → 互動 → 做完 → 「為什麼？」（按了才唸，大人可以一起聽）＋「繼續」。

## 內容依據

中央氣象署〈颱風百科〉與颱風警報說明（颱風警報期間每 3 小時發布一次）、香港天文台〈熱帶氣旋名字的意思〉（颱風委員會 14 個成員輪流命名；Champi 由寮國提供）。颱風生成需要約 26.5°C 以上的海水；北半球逆時針旋轉；颱風眼風小、眼牆風雨最強；移動受駛流與太平洋高氣壓導引，秋季副高東退、西風帶南移，颱風常在臺灣東方轉向北；遇冷海水或登陸後減弱，常轉為溫帶氣旋。
