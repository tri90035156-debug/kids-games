## 十關

| 關 | 標題 | 3D 動作（鍵盤） |
|---|---|---|
| 1 | 嗨！這是颱風 | 點海上那團黏土颱風三下，它越轉越快、越長越大（空白鍵） |
| 2 | 颱風怎麼生出來？ | **按住**太陽（或按鈕），海水變暖色、溫度升高、水蒸氣往上飄、雲聚起來長成颱風（按住 H） |
| 3 | 颱風為什麼會轉圈圈？ | 按「讓地球轉起來」，風的小點點從直直衝向中間變成往右彎；再用手指**逆時針畫圈**轉颱風（← →） |
| 4 | 颱風長什麼樣子？ | 從上面看一個大颱風，點颱風眼、眼牆、雨帶（亮一圈＋標籤）；可以放一個立體臺灣比大小（空白鍵） |
| 5 | 颱風為什麼會走路？ | 在水面上**拖出水流方向**，樹葉跟著漂、碰三顆星星（方向鍵） |
| 6 | 颱風通常怎麼走？ | 在黏土東亞地圖上**拉大拉小**太平洋高氣壓（半透明的圓頂），颱風照著走一條紅線；也可以按三顆按鈕（1 2 3），再看常走的路（Enter） |
| 7 | 颱風來了，怎麼辦？ | 防颱小任務六樣 3D 東西，**拖到**「好」（綠墊子）或「不好」（紅墊子）（A／B） |
| 8 | 經過臺灣以後，颱風去哪裡？ | 按「繼續走」三次，颱風在地圖上往北：沖繩、東海、九州（Enter） |
| 9 | 颱風怎麼會消失？ | **拖著**颱風去冷海、爬上有山的陸地，力氣條變成零、颱風變成一朵雲（方向鍵） |
| 10 | 你是颱風小博士！ | 四題，每題兩個 3D 答案（暖海水／雪、順時針／逆時針轉的小颱風…）點一個（A／B） |

配音稿一句沒改、沒重錄（第 5 批 0 點）。同一畫面物件最多 21 個（颱風的雲臂是一個 InstancedMesh）。

每關：故事一句一句唸 → 要做的事 → 互動 → 做完 → 「為什麼？」（按了才唸，大人可以一起聽）＋「繼續」。

## 內容依據

中央氣象署〈颱風百科〉與颱風警報說明（颱風警報期間每 3 小時發布一次）、香港天文台〈熱帶氣旋名字的意思〉（颱風委員會 14 個成員輪流命名；Champi 由寮國提供）。颱風生成需要約 26.5°C 以上的海水；北半球逆時針旋轉；颱風眼風小、眼牆風雨最強；移動受駛流與太平洋高氣壓導引，秋季副高東退、西風帶南移，颱風常在臺灣東方轉向北；遇冷海水或登陸後減弱，常轉為溫帶氣旋。
