# 頌缽工坊

給 6 歲小朋友的互動遊戲，十關跟著師傅把銅和錫做成一個會唱歌的頌缽。每關一種不同的玩法：

| 關 | 主題 | 玩法 |
|---|---|---|
| 1 | 聽頌缽唱歌 | 點一下「噹」；再用手指**繞圈圈**磨缽口，讓它唱歌（真的會發出聲音） |
| 2 | 缽這個字 | 把「缶」和「本」**拖**進格子拼成「缽」，再認識「鉢」 |
| 3 | 找金屬 | **一直點**石頭把它敲開，找出銅礦和錫礦 |
| 4 | 調配方 | 四塊銅加一塊錫**拖**進鍋子；錫放太多會被提醒 |
| 5 | 生火 | **上下拉**風箱（或輪流按 `W` `S`），把金屬燒到融化 |
| 6 | 倒進模子 | **按住**倒青銅，到金線就放開 |
| 7 | 趁熱敲打 | 跟著師傅們的**節奏**，輪到你時按空白鍵；冷了要拖回火裡 |
| 8 | 泡冷水 | 把缽**拖**進火裡燒紅，再拖進水桶「滋——」 |
| 9 | 磨亮亮 | 用手指在黑黑的缽上**來回擦**，擦出金色 |
| 10 | 大缽小缽 | 敲三個大小不同的缽比較音高；再把水倒進缽裡磨，看水跳舞 |

每關結尾有小字「給家長」，放成分比例、溫度、工法的正確補充。

## 開始玩

雙擊 `index.html`。測試用網址：`index.html?ch=3` 直接到第 3 關；加 `&fast=1` 旁白不等待（只給測試用）。
頌缽的聲音是用瀏覽器即時合成的音效（不是語音），旁白一樣只播 VoAI 錄好的 mp3。

## 文字、注音、配音

跟種子遊戲一樣：改 `tools/content.py` → `python3 tools/build.py` → `python3 tools/make_voice.py`。

## 重來鈕（2026-11-08）

- 右上角聲音鈕旁邊的圓箭頭「↻」（`restart.js`，九個遊戲共用、檔案一模一樣）：按下去木魚一聲、旁白停下，重新載入到這一關（`?ch=N`，網址參數自動清掉），第 N 關重來還是第 N 關，進度不丟。封面、結尾不出現。同一關 90 秒沒有答對或按「繼續」，鈕會輕輕呼吸提醒；孩子一碰畫面就停。測試：`?fin=1` 直接看結尾。

## 3D 版（2026-11-08 第 8 批）

場景是**一張長長的黏土工作檯**（後面一面牆），缽沿著檯子一站一站往右；每關開始鏡頭從左邊一點滑過去。頌缽用 LatheGeometry 轉出來（青銅色，有一圈缽口）。
**磨缽聲照舊用 WebAudio 即時合成**（`G.hum`：木棒繞得越快越響，還有一圈一圈金色波紋）；**擦亮手感照舊**（缽外面一層黑皮是 canvas 貼圖，手指擦到的地方真的一塊一塊被擦掉，露出亮的青銅）。

| 關 | 3D 才有的動作 | 鍵盤 |
|---|---|---|
| 1 聽頌缽唱歌 | 點缽敲一下（波紋＋缽聲），再用手指**繞著缽口畫圈**，木棒跟著轉、缽唱歌 | D、按住空白鍵 |
| 2 缽這個字 | 把「缶」「本」兩塊**字的積木拖進**木牌左右兩格，變成「缽」；再看「金＋本＝鉢」；最後點 3D 的金屬缽／木頭／塑膠 | A B 再按 ← →、A B C |
| 3 找金屬 | **一直敲**三塊石頭（槌子落下、石頭一次比一次裂），裂開找銅礦、錫礦 | 1 2 3、K |
| 4 調配方 | 把四塊銅、一塊錫**拖進坩堝**，坩堝裡的顏色跟著變 | A B |
| 5 生火 | 上下**拉風箱**（風箱真的被壓扁），火越來越高、坩堝越來越紅 | W S 輪流 |
| 6 倒進模子 | **按住**，坩堝傾斜倒出金屬液，模子裡的液面升高，到白線放手（兩次） | 按住空白鍵 |
| 7 趁熱敲打 | 師傅輪流舉槌，第四下**換你敲**（跟著節奏），金屬餅越敲越深；冷了把它**拖回火裡** | 空白鍵 |
| 8 泡冷水 | 把缽**拖進火爐**燒紅，再拖進冷水桶（滋——冒白煙，缽變黑） | ← → |
| 9 磨亮亮 | 手指在缽上**來回擦**，黑皮一塊一塊擦掉 | A D |
| 10 大缽小缽 | 敲三個大小不同的缽，找最低的聲音；把水壺拖過去倒水，**繞圈磨**，水面跳、水珠跳起來 | 1 2 3、按住空白鍵 |

- **配音稿一句沒改、沒重錄**（0 點）；每關結尾的「給家長」小卡文字照舊。
- 同一畫面物件最多 21 個。共用 `sound.js` 這批加了 crack、clang、whoosh、beep、step（六份同步）。
- 測試：`node pipeline/play3d.mjs --game bowl-game --hook __bw --mode kb|ptr`；console `__bw.win()`、`__bw.aid()`。
