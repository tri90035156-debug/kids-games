# 高質感兒童網頁：設計語彙與夜間查核原則

給夜間流水線裡的每個角色（搜尋、查核、建置、試玩、評審）看，也給家長看。
對象：6 歲、看得懂注音、認得鍵盤 ABC；家長在旁邊。整體氣質＝「安靜、溫暖、高質感的玩具」，不是卡通頻道。
根目錄 `設計原則.md` 是視覺與首頁的完整版；這份補的是「每一關怎麼做、怎麼檢查、怎麼進步」。

## 一、核心設計語彙（不可退讓）

1. **聽覺（Sound Design）**：木質敲擊（馬林巴、木魚）、水滴、輕柔和弦；音高走五聲音階；全部 WebAudio 現場合成。
   一種事件一種聲音。成功＝上行三音，答錯＝低一點的木魚一聲（不是蜂鳴）。連續觸發要降音量或換音高。
   禁止：尖銳卡通音、電子嗶嗶、鋸齒波、白噪音、系統朗讀。
2. **物理慣性（Physics-based）**：拖曳有重量（跟手但略慢，lerp 0.2～0.35）；放手有阻尼滑行；落點 squash & stretch（壓到 0.85 → 回彈 1.08 → 1.0，180～260ms）；答錯是彈回原位，不是瞬移。
3. **低文字、高直覺符號**：畫面最多一行字。用游標形狀、同色呼吸光暈、手勢示範動畫指出下一步。
   5 秒沒動作 → 光暈亮一點；15 秒 → 播一次手勢示範。注音只做輔助，字母鍵帽畫在物件上。
4. **視覺**：米白底、4～5 個高彩焦點、霧面黏土、暖光軟影；無描邊、無 emoji、無彩紙、無刻意幼兒化。
5. **每一關一種互動**：點、拖、畫線、繞圈、按住、排順序、配對、節奏敲、左右拖看變化、找不同、搖一搖……
   連續兩關不重複；主題風格不換，換的是「手怎麼動」。

## 二、檢查與優化的 12 條原則（評審每晚照這張表打 1～5 分）

| # | 原則 | 看什麼 | 低分的典型樣子 |
|---|---|---|---|
| 1 | 互動戲 | 每個看得到的物件都有反應：hover 微晃＋游標變手、按下壓扁、放開回彈；背景會「活」（呼吸光暈、慢漂浮）但不搶戲 | 只有正確答案會動，其他都是死圖 |
| 2 | 美感 | 主色＋2 輔色＋焦點色，不再多；留白；標題 serif 900 一行；圖大字少（主圖平板 ≥ 240px）；圓角、陰影、材質一致 | 顏色很多、字很多、元素擠在一起 |
| 3 | 聲音 | 材質對（木、水、和弦）、音量小、節制、成功音有上行感 | 每次點都同一聲、太大聲、電子音 |
| 4 | 手感 | 拖曳跟手、放下有重量、回彈不過頭；觸控目標 ≥ 44px；`user-select:none`、`touch-action:none` | 拖起來飄、放下瞬移、手指按住選到文字 |
| 5 | 直覺 | 把字全遮掉還能玩嗎？第一眼知道能碰什麼？下一步有光暈／游標／示範嗎？ | 要看字才知道做什麼 |
| 6 | 關卡多樣 | 這關跟前一關的動作不同？整個遊戲至少 6 種動作？ | 十關都是點選 A/B/C |
| 7 | 溫柔的失敗 | 答錯只有回彈＋輕搖＋低木魚；沒有紅叉、倒數、扣分；錯兩次給光暈提示，錯三次示範 | 大紅叉、嗶聲、時間壓力 |
| 8 | 內容正確 | 事實對（孩子會追問）；「給家長」小字有數字與來源；適齡、不嚇人；注音破音字對 | 數字錯、簡化到錯、注音錯 |
| 9 | 效能穩定 | 手機 375／平板 768 無橫向捲動、無 console error、首屏 < 2 秒、離線（除字型）可玩、`?ch=N` 可直達 | 有錯誤、手機要左右捲 |
| 10 | 完成感 | 每關結尾一個小儀式（物件歸位、印章、和弦）；進度點看得見；全部完成有結尾場景 | 答對就直接跳下一關 |
| 11 | 原創 | 只借機制，不拿別人的圖、音、角色、名字；全部自己畫 SVG、合成聲音 | 用了外部圖片或音檔 |
| 12 | 家長看懂 | README 有關卡表；報告第一段三句話講清楚今晚做了什麼、哪裡還不好 | 要看程式碼才知道 |

## 三、每晚優化的進步法（挑最弱的兩項，不貪多）

- 順序：先修「阻擋」（錯誤、壞掉、內容錯、橫向捲動），再修分數最低的兩項原則，其他留到下一晚。一晚改太多容易回歸。
- 每次改動要「看得見」：改前、改後各一張截圖放進報告。
- **互動戲升級階梯**：靜止 → hover 回應 → 按下回饋 → 拖曳慣性 → 環境會回應（背景物件被碰會晃）→ 物件互相影響（連鎖）。每晚升一階就好。
- **美感升級階梯**：配色收斂 → 間距節奏（8px 格）→ 字級層級 → 陰影材質一致 → 進退場動畫（ease-out-back, 240ms）→ 細節（圓角一致、光暈同色）。
- **聲音升級階梯**：有聲 → 材質對 → 音高隨進度變化（越接近完成越高）→ 和弦收尾 → 音量自動避讓（連點變小聲）。
- **直覺升級階梯**：有字說明 → 字變圖示 → 光暈指路 → 游標示範 → 第一次互動後提示自動淡出。

## 四、閘門

- **可以上首頁**（第一晚就自動上，家長從首頁點進去檢查）：沒有阻擋項，且「8 內容正確」≥ 4、「9 效能穩定」= 5。
  上首頁＝多一個 `hub/entries/<slug>.js` 入口檔（3D 黏土小物件＋徽章）＋ `hub/entries.json` 加一行；首頁本身零錯誤才算。
- **打磨完成**（開始做下一個）：12 項全部 ≥ 4，或已打磨三晚。
- 任一晚出現阻擋 → 不推新東西，只修。正式四個遊戲或首頁壞了 → 只記錄給家長，不修。
