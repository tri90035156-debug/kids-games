# 種子小偵探

給 6 歲小朋友的種子互動遊戲，約 15 分鐘玩完 7 關，再加 1 個加碼關：

1. 找種子（蘋果、芒果、松果裡面都有種子）
2. 種子怎麼來（花裡有種子寶寶 → 蜜蜂送花粉 → 種子和果實一起長 → 一起熟）
3. 種子變成樹（按 `W` 澆水、按 `S` 曬太陽）
4. 認識種子（橡實、松果、楓樹、椰子、芒果、蘋果）
5. 種子配對（這個種子會長成哪種樹？）
6. 種子去旅行（風、水、小動物）
7. 種子的一生（排順序）
8. 加碼關：最早的種子（孢子 → 種子 → 花和果實，種子比花還早出現）

**給孩子的設計**：所有字都標注音（注音在字的右邊）、答案用鍵盤 `A` `B` `C`（也可以點）、種樹用 `W` `S`、答錯不扣分只會提示。

## 開始玩

雙擊 `index.html` 就能玩（用 Chrome 或 Safari）。測試時可以用網址 `index.html?ch=3` 直接跳到第 3 關。
進度會存在瀏覽器裡，中途離開再開會問要不要「繼續上次」。

## 配音：用 VoAI（雅琪）

遊戲**只會播 VoAI 錄好的 mp3**，不會用瀏覽器內建的聲音。還沒錄配音之前，遊戲是安靜的，文字照常顯示。
金鑰只放在你電腦的 `.env`，不會進到網頁；錄好之後玩的時候不再扣點、也不用連網。

```bash
cd seed-game
cp .env.example .env            # 然後打開 .env，貼上 VOAI_API_KEY=你的金鑰
python3 tools/make_voice.py --list-speakers     # 查雅琪有哪些「風格」
```

配音員、風格、速度在 `tools/voai.config.json`（目前：雅琪／預設／速度 0.9）。如果「預設」不是雅琪的風格，
用上面指令查到的名稱改掉 `style`。然後：

```bash
python3 tools/make_voice.py --sample "嗨！我是松鼠果果。"   # 先試聽一句 → audio/_sample.mp3
python3 tools/make_voice.py --dry-run                        # 估算點數（1 字 = 1 點）
python3 tools/make_voice.py                                  # 錄全部旁白到 audio/（已錄過的會跳過）
```

- 已經錄過的句子會自動跳過；改了某一句文字，重跑只會錄那一句。
- 換配音員或風格後，用 `--force` 全部重錄。
- 試用金鑰錄出來的音檔會有浮水印／背景音樂，要用付費點數錄才乾淨。

## 修改文字

所有旁白、題目都在 `tools/content.py`。改完執行：

```bash
pip install pypinyin      # 第一次需要
python3 tools/build.py    # 自動加注音、更新 content.js 和配音清單
python3 tools/make_voice.py
```

破音字若自動注音錯了，在字後面手動指定，例如 `種[ㄓㄨㄥˋ]樹`。`{W}` 會顯示成鍵盤上的 W 鍵。
注音一律用原調（「一」「不」不變調），跟 `怎麼做成的.html` 一致。

## 重來鈕（2026-11-08）

- 右上角聲音鈕旁邊的圓箭頭「↻」（`restart.js`，九個遊戲共用、檔案一模一樣）：按下去木魚一聲、旁白停下，重新載入到這一關（`?ch=N`，網址參數自動清掉），第 N 關重來還是第 N 關，進度不丟。封面、結尾不出現。同一關 90 秒沒有答對或按「繼續」，鈕會輕輕呼吸提醒；孩子一碰畫面就停。測試：`?fin=1` 直接看結尾。

## 3D 版（2026-11-08 第 6 批）

場景是**一條黏土花園小徑**（草地＋石板路），一關往右走一段：每關開始鏡頭從左邊一點慢慢滑過去，像沿著小徑往右走。
**接上共用引擎**（`engine.js`：封面、標題卡、`?ch=N`、重來鈕、字幕泡泡＋配音），原本 app.js 裡自己寫的流程拿掉；3D 用共用的 `kit3d.js`，場景在 `garden.js`。

| 關 | 3D 才有的動作 | 鍵盤 |
|---|---|---|
| 1 找種子 | 手指**劃過**果實（蘋果、芒果、松果）把它切開，兩半往兩邊倒、看到種子 | 1 2 3 |
| 2 種子怎麼來 | **照順序點**：開花、蜜蜂送花粉、小果實、熟了，一個一個跳到小圓盤上 | 1～4 |
| 3 種子變成樹 | 點泥土種下去；**拖澆水壺**到花盆上澆水（水滴往下掉）、點太陽，樹一段一段長高（種子變胖、長根、發芽、長葉、樹苗、大樹） | W／S |
| 4 認識種子 | **按住**一顆種子，它的樹從種子後面長出來，再唸它的介紹 | 按住 1～6 |
| 5 種子配對 | 看一顆種子，**點**它會長成的那棵樹，種子跳過去 | A B C |
| 6 種子去旅行 | 把種子**丟給**風、水或松鼠：風把楓樹種子吹高飛遠、椰子在水上漂走、松鼠把橡實埋進土裡冒出小芽 | A B C |
| 7 種子的一生 | **照順序點**，五個階段排成一圈（種子→發芽→長大→開花→結果→又是種子） | 1～5 |
| 8 最早的種子 | 把孢子（蕨類）、種子（松果）、花**拖到**木頭時間軸上 | 1 2 3 |

- 第 1、2、3、8 關最後的「選一個」也是點 3D 東西（A B C）。
- **配音稿一句沒改、沒重錄**（0 點）。
- 同一畫面物件最多 46 個。手機直的：第 7 關排兩排，名字標籤在種子長出樹以後才出現（不擠）。
- 測試：`node pipeline/play3d.mjs --game seed-game --hook __sd --mode kb|ptr --n 8`；console `__sd.win()`、`__sd.aid()`。

| 檔案 | 用途 |
|---|---|
| `app.js` | 八關 |
| `garden.js` | 花園小徑、果實（切開的）、花、蜜蜂、花盆、澆水壺、會長大的樹、六種種子與六種樹、風、小溪、松鼠、蕨類 |
| `engine.js` `restart.js` `style.css` | 共用引擎（和其他關卡式遊戲一模一樣） |
| `kit3d.js` `kit3d.css` `space.js` `sound.js` | 共用 3D 工具與音效（和小水滴一模一樣） |
| `art.js` | 封面的小圖 |
