# AI 從哪裡來

給 6 歲小朋友的互動遊戲，十關認識「為什麼會有 AI、AI 是怎麼來的」。每關一種不同的玩法：

| 關 | 主題 | 玩法 |
|---|---|---|
| 1 | 人愛做工具（為什麼有 AI） | 把工具**拖**到它幫忙的身體部位 |
| 2 | 電腦照著做（程式） | 用**方向鍵**排步驟，讓機器人走到星星 |
| 3 | 規則不夠用 | 選一條規則，看電腦把狐狸當成貓 |
| 4 | 你來當老師（機器學習） | 把照片**拖／左右鍵**分進「是貓／不是貓」籃子 |
| 5 | 猜錯了再改 | 電腦猜，你按 `O` / `X` 判斷；猜錯會轉旋鈕 |
| 6 | 學大腦連一連（神經網路） | 用手指**畫線**把點連起來，看消息傳過去 |
| 7 | 例子要很多（資料） | **按住**把照片倒進電腦，放開就考試 |
| 8 | 電腦長大了（歷史） | 把電腦的演變**拖**到時間線上 |
| 9 | 猜下一個字（會聊天的 AI） | 把最可能的詞拖進空格；再按空白鍵看 AI 一個詞一個詞說故事 |
| 10 | AI 也會出錯 | 在 AI 畫的圖裡**找**三個錯，最後選「想請 AI 幫什麼」 |

每關結尾有小字「給家長」，放年代與正確的補充說明。

## 開始玩

雙擊 `index.html`。測試用網址：`index.html?ch=3` 直接到第 3 關；加 `&fast=1` 旁白不等待（只給測試用）。

## 文字、注音、配音

跟種子遊戲一樣：改 `tools/content.py` → `python3 tools/build.py` → `python3 tools/make_voice.py`（雅琪／聊天／0.9，設定在 `tools/voai.config.json`，金鑰在 `.env`）。
`build.py` 會固定幾個常錯的讀音：「得」→˙ㄉㄜ、「片」→ㄆㄧㄢˋ、「錫」→ㄒㄧˊ。

| 檔案 | 用途 |
|---|---|

## 重來鈕（2026-11-08）

- 右上角聲音鈕旁邊的圓箭頭「↻」（`restart.js`，九個遊戲共用、檔案一模一樣）：按下去木魚一聲、旁白停下，重新載入到這一關（`?ch=N`，網址參數自動清掉），第 N 關重來還是第 N 關，進度不丟。封面、結尾不出現。同一關 90 秒沒有答對或按「繼續」，鈕會輕輕呼吸提醒；孩子一碰畫面就停。測試：`?fin=1` 直接看結尾。

## 3D 版（2026-11-08 第 7 批）

場景是**一張方形黏土書桌**，中間一台會笑的電腦（螢幕上的臉會笑、會想、會「糟糕」；背後三顆旋鈕），每關桌上換道具。相機固定斜斜往下看。
照片卡＝白色黏土小卡，貼上原本 `art.js` 畫的動物圖（這個遊戲本來就是在分照片，照片是平的）。

| 關 | 3D 才有的動作 | 鍵盤 |
|---|---|---|
| 1 人愛做工具 | 把槌子、腳踏車、眼鏡、電話**拖到人偶身上**（手、腳、眼睛、耳朵），最後 AI 晶片拖到頭上 | A～D 再按 1～4、E |
| 2 電腦照著做 | 按箭頭排步驟（桌上出現一排小方塊），按「出發」，小機器人在桌上的格子裡一步一步走 | ← ↑ ↓ →、X、G |
| 3 規則不夠用 | **拉一根規則拉桿**，四張照片卡被蓋上 ○ 或 ✕，電腦的臉變「糟糕」 | A B |
| 4 你來當老師 | 把照片卡**丟進**「是貓／不是貓」兩個籃子，電腦旁邊的學習條變長 | ← → |
| 5 猜錯了再改 | 電腦頭上冒出它猜的 ○ 或 ✕，**點**桌上的 ○ 或 ✕ 方塊；猜錯時電腦背後的三顆旋鈕真的轉 | O X |
| 6 學大腦連一連 | 在三排小球之間**拉黏土線**（神經網路），連好以後消息光點沿線跑到「貓」 | A～F 兩兩 |
| 7 例子要很多 | **按住**，照片一張一張倒進電腦上的漏斗，數字一直變大；放手就考試（六張照片蓋 ○✕） | 按住空白鍵 |
| 8 電腦長大了 | 把五台電腦（整個房間的大電腦、一群科學家、桌上電腦、手機、會聊天的手機）**拖上時間線** | A～E 再按 1～5 |
| 9 猜下一個字 | **點**字的積木，它跳進句子的空格；再按一下，AI 就接一個詞 | A B C、空白鍵 |
| 10 AI 也會出錯 | 桌上 AI 畫的小場景，**點出**三個怪怪的地方（兩條尾巴的貓、長在樹上的魚、開在屋頂的門），再選一個願望 | 1 2 3、A～D |

- **配音稿一句沒改、沒重錄**（0 點）。每關結尾的「給家長」小卡文字照舊。
- 同一畫面物件最多 54 個（第 2 關）。共用 `kit3d.js` 這批加了 `dropScreen`（放手時用手指在畫面上的位置判斷，人偶這種立著的目標用）。
- 測試：`node pipeline/play3d.mjs --game ai-game --hook __ai --mode kb|ptr`；console `__ai.win()`、`__ai.aid()`。
