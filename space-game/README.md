# 太陽系大探險

給 6 歲小朋友的 3D 互動遊戲（three.js）。夜空裡的一座黏土太陽系模型：孩子開一台小火箭自由飛，飛到星球旁邊就能進去做任務。
**不配音**：幾乎沒有字，用形狀、顏色、光暈和字母鍵帽帶孩子自己試；需要的字一律標注音。

## 怎麼玩

- **開火箭**：桌機用 `W A S D`／方向鍵；平板和手機「按在哪裡，哪裡就是搖桿」，手指往哪拖火箭就往哪飛。放手會滑行再停，撞到星球會壓扁再彈回來，小行星帶的石頭會被推開。
- **進星球**：還有任務的星球底下有一圈同色的呼吸光暈，越近越亮；飛近時名字浮出來，按 `E` 或點名字進去。
- **不會開也沒關係**：點星球上方的圓形徽章，或按徽章角落的數字鍵（1 太陽、2 水星 … 9 海王星、0 月亮），火箭自己飛過去。看不到的星球，徽章會貼在畫面邊緣指方向。
- 鏡頭固定朝北、不旋轉，手指方向＝世界方向。

## 任務（共 16 個）

| 星球 | 任務 |
|---|---|
| 太陽 | 按住 `F` 往前飛，小星星變成太陽 |
| 水星、金星、天王星、海王星 | 認識它，再把太空船拖上去試降落（`L`） |
| 地球 | 認識＋試降落 → 畫圓圈繞太陽一年 → 左右拖看白天晚上 → 拖地球找「剛剛好」的距離 |
| 月亮 | 拖月亮繞地球，變出滿月、半月、新月 |
| 火星 | 認識＋試降落 → 看準時機按 `G` 發射火箭去火星 |
| 木星 | 認識＋試降落 → 連按 `E` 排地球量木星有多大 |
| 土星 | 認識＋試降落 → 往上滑飛近看環、左右拖從側面看 |

每個任務最後有小字「給家長」，放數字與正確的補充說明。全部做完看結尾。

## 畫風與手感

- 黏土微縮模型：霧面材質、沒有描邊；太陽是暖色光源，星球、火箭、石頭的影子落在深藍底座上，底座邊緣木頭收邊，鏡頭斜 40° 俯視，有移軸鏡頭的上下模糊。
- 每顆星球一張黏土小臉（太陽戴墨鏡、月亮想睡、海王星冷得發抖、天王星的臉是躺著的）。
- 聲音全部用 WebAudio 現場合成：木琴（五聲音階，怎麼撞都好聽）、木魚、水滴、輕柔和弦；引擎是很低很小的嗡嗡聲。沒有音效檔、沒有系統朗讀。
- 物理：彈簧＋阻尼的果凍回彈（`S3.jelly / poke / wobble`）。

## 開始玩、測試

雙擊 `index.html`（three.js 在 `vendor/`，不用網路；只有字型要網路）。
測試用網址：`?world` 跳過開場直接進太陽系；`?act=earth.c3` 直接做某個任務（星球.任務）；加 `&fast=1` 動畫和等待變快。

## 改文字

改 `tools/content.py` → `python3 tools/build.py`（需 `pip install pypinyin`）。所有句子都在 `UI`（只顯示、不配音）；以後想配音，搬到 `SAY` 再跑 `tools/make_voice.py`。

## 檔案

| 檔案 | 用途 |
|---|---|
| `world.js` | 太陽系世界：底座、星球、小臉、小火箭、搖桿、自動駕駛、徽章 |
| `app.js` | 任務（`TASKS` 把任務分到星球）、拜訪星球、流程與進度 |
| `space.js` | three.js 小工具：畫布、黏土材質、行星貼圖、土星環、果凍回彈、移軸後製 |
| `sound.js` | 柔和音效（覆寫共用引擎的 `G.sfx`）與引擎聲 |
| `engine.js` `style.css` | 和其他遊戲共用的引擎（注音排版、拖拉、按住…），沒改 |
| `game.css` | 這個遊戲的滿版樣式 |
| `art.js` | 小圖示（提示的手、月相、蛋糕、太空船…） |
| `content.js` | 由 `build.py` 產生，不要手改 |
